# GreyVendorTrash

## v1.1.0 — 2026-09-26

- Added support for World of Warcraft Forever.
- Added an AddOns settings panel.
- Added optional poor-quality item desaturation.
- Added adjustable greyscale darkness from 0% to 75%, defaulting to 25%.
- Added an option to keep Blizzard's native junk coin visible outside merchants.
- Restricted all visual changes to player inventory bags only; merchant, buyback, bank, guild bank, and other item displays remain unchanged.
- Refactored client compatibility into a shared compatibility layer.
- Added automated GitHub/CurseForge packaging support.
